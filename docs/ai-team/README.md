# تیم دستیارهای تخصصی — AI Creative Earnings

وضعیت: **۶ نقش تخصصی تعریف شده‌اند؛ عامل اجرایی هنوز فعال نشده است.**

این فایل‌ها شرح وظایف دستیارها هستند، نه شش مدل مستقل. اجرای خودکار فقط پس از نصب و کامپایل workflow، تنظیم امن احراز هویت موتور AI و اجرای آزمایشی اثبات می‌شود.

## ترکیب تیم

| شناسه | دستیار | مسئولیت |
|---|---|---|
| manager | مدیر تیم | اولویت‌بندی، تقسیم کار، هماهنگی و کنترل ریسک |
| opportunity-scout | شکارچی فرصت | کشف فرصت‌های درآمدی و بررسی منابع عمومی |
| eligibility-payout | متخصص پذیرش و پرداخت | بررسی عمومی کشور، KYC، روش پرداخت، کارمزد و هزینه شروع |
| creative-producer | تولیدکننده محتوا | ارزیابی گردش‌کار تصویر، ویدئو، صدا، موسیقی و نوشتن |
| client-acquisition | جذب مشتری | یافتن سفارش‌ها و مشتریان خدمات خلاقانه، بدون انتشار پست در حساب‌های کاربر |
| auditor | بازرس کیفیت | راستی‌آزمایی شواهد، تست‌ها، امنیت و ادعاهای محصول |

## محدوده انحصاری

این تیم فقط روی **AI Creative Earnings / پروژه درآمد دلاری** کار می‌کند. پروژه‌های AI Crypto Security Hunter، AIRDROP AI، Global Job Intelligence و سایر پروژه‌ها خارج از محدوده‌اند و نباید از زمان، ابزار یا بودجه این تیم استفاده کنند.

## قواعد محصول

1. فرصت‌های تصویر/طراحی، ویدئو، صدا/موسیقی، نویسندگی/مقاله، نظرسنجی/رأی‌گیری، فریلنسری و کار دورکاری را بررسی کن.
2. پیشنهادهای نصب یا تست بازی را حذف کن.
3. فرصت نیازمند سپرده، اشتراک اجباری، هزینه آزادسازی برداشت یا پرداخت اولیه را رد کن.
4. وضعیت نامشخص کشور/KYC/پرداخت را حذف نکن؛ با برچسب «ریسک احراز هویت نامشخص» به بررسی انسانی ارجاع بده.
5. کاتالوگ، فید عمومی متصل، فید زنده تأییدشده و فرصت واجدشرایط را از هم جدا کن.
6. برای ادعاهای مهم لینک رسمی، تاریخ بررسی، سطح اطمینان، روش پرداخت، کارمزد و حداقل برداشت ثبت کن.
7. هیچ درآمدی را قبل از دریافت واقعی پول قطعی معرفی نکن.
8. هیچ ثبت‌نام، KYC، OTP، CAPTCHA، اتصال/امضای کیف پول، پیشنهاد نهایی، انتشار عمومی یا تراکنش مالی بدون تأیید صریح کاربر انجام نشود.
9. هیچ رمز، OTP، عبارت بازیابی، کلید خصوصی یا API Secret در Git ثبت نشود.
10. اطلاعات هویتی و پروفایل شخصی کاربر، از جمله گذرنامه، تابعیت، محل اقامت، حساب‌ها و کیف پول‌ها، به موتورهای مدل خارجی ارسال یا در گزارش عمومی تکرار نشود. بررسی عمومی شرایط پلتفرم‌ها انجام شود و تطبیق شخصی تا زمان وجود اتصال امن و تأییدشده، انسانی باقی بماند.
11. هیچ API پولی، تولید پولی، اشتراک یا افزایش سقف هزینه بدون تأیید صریح کاربر فعال نشود.

## گردش کار تیم

1. شکارچی فرصت: منابع و فرصت‌های جدید را با شواهد رسمی ثبت می‌کند.
2. متخصص پذیرش و پرداخت: شرایط عمومی KYC، کشور، پرداخت و هزینه را بررسی می‌کند.
3. تولیدکننده محتوا: امکانات تولید و محدودیت رایگان/پولی را ارزیابی می‌کند.
4. جذب مشتری: سفارش‌های خلاقانه واقعی را بررسی می‌کند.
5. بازرس: شواهد، کد، تست و ادعاهای سایر نقش‌ها را بازبینی می‌کند.
6. مدیر تیم: خروجی‌ها را اولویت‌بندی و به کارهای کوچک و قابل پیگیری تبدیل می‌کند.
