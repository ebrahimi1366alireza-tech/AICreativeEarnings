# تیم دستیارهای تخصصی — AI Creative Earnings

وضعیت: **شش نقش تخصصی و دستورالعمل‌های Copilot در مخزن تعریف شده‌اند؛ اجرای مستقل یا زمان‌بندی‌شده دستیارها فعال نیست. مسیر تأییدشده فعلی: GitHub Copilot از مرورگر، با استفاده از مخزن و دستورالعمل‌های همین پروژه.**

## محدوده فعلی

- تنها پروژه فعال این تیم: **AI Creative Earnings** (پروژه درآمد دلاری).
- AIRDROP AI پروژه‌ای جداست.
- AI Crypto Security Hunter فعلاً متوقف است و نباید توسط این تیم پیش برده شود.
- Global Job Intelligence و ARVZENO نیز تا اعلام صریح کاربر متوقف/موکول هستند.

## قواعد مشترک

1. شرایط عمومی کشور، مدارک و KYC هر پلتفرم باید از منبع رسمی بررسی شود؛ تطبیق با پروفایل شخصی کاربر تا زمان وجود اتصال امن، بررسی انسانی است.
2. فرصت با KYC یا کشور نامشخص حذف نشود؛ با برچسب «ریسک احراز هویت/کشور نامشخص — نیازمند بررسی انسانی» نمایش داده شود.
3. سپرده، اشتراک اجباری، خرید اولیه، هزینه آزادسازی برداشت و هزینه اجباری پیشنهاد رد شود.
4. پرداخت هدف، رمزارز مستقیم به کیف پول شخصی کاربر است؛ هیچ کوین یا توکنی اولویت ندارد.
5. هیچ API یا زیرساخت پولی بدون اجازه روشن کاربر فعال نشود.
6. ثبت‌نام، KYC، اتصال/امضای کیف پول، ارسال پیشنهاد، پیام به مشتری، انتشار یا تراکنش نیازمند تأیید صریح کاربر در همان مرحله است.
7. فرصت‌ها و درآمدها تضمین‌شده معرفی نشوند؛ ادعاهای مهم باید منبع رسمی و تاریخ بررسی داشته باشند.
8. اپ فرصت‌های پولی را پیدا و دسته‌بندی می‌کند؛ در حساب‌های اجتماعی کاربر پست منتشر نمی‌کند.
9. پیشنهادهای نصب/تست بازی حذف شوند.

## وضعیت اجرایی و ابزار مورد توافق

- [x] شش نقش تخصصی و حدود مسئولیت آن‌ها مستند شده‌اند.
- [x] دستورالعمل‌های مخزن برای GitHub Copilot در `.github/copilot-instructions.md` ثبت شده‌اند.
- [x] گردش‌کار قدیمی مبتنی بر Gemini و فایل lock تولیدشده آن حذف می‌شوند؛ اجرای شکست‌خورده یا زمان‌بندی روزانه دیگر مبنای کار نیست.
- [ ] اجرای هر نقش در GitHub Copilot باید در همان نشست و با بررسی خروجی مستند شود.
- [ ] جست‌وجوی جهانی فرصت‌ها تا اتصال و آزمایش منبع جست‌وجوی معتبر، محدودیت شناخته‌شده باقی می‌ماند.

**تصمیم ابزار:** Gemini، Amazon Q و Ollama کنار گذاشته شده‌اند. مسیر مورد تأیید اخیر، GitHub Copilot از مرورگر است. GitHub Copilot Free را نباید دارای Cloud Agent یا اجرای خودکار پس‌زمینه فرض کرد. OpenCode در محیط Codespaces و Free Claude Code قبلاً به‌عنوان ابزارهای مکمل بررسی شده‌اند، اما در این مرحله اجرای خودکار آن‌ها نیز تأیید نشده است.

هیچ کلید API یا Secret جدیدی برای Gemini درخواست یا فعال نمی‌شود. هیچ سرویس پولی، مدل پولی یا اجرای زمان‌بندی‌شده بدون تأیید صریح کاربر فعال نخواهد شد.
