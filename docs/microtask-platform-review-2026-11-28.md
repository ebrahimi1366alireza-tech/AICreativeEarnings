# Microtask platform review — 2026-11-28

This is a source review, not an account-eligibility approval. No account was created, no identity document was submitted, and no task was accepted.

## Microworker.app

Official worker-facing information reviewed:
- Workers join for free; approved task rewards have no worker-side platform fee.
- Cash-out is documented from USD 5, in USDT or USDC on BNB Smart Chain (BEP20), to the worker's own crypto wallet.
- Earnings become withdrawable three days after they are paid to the worker balance.
- The platform states that it is unavailable in Iran. This is a location restriction and must not be bypassed.
- The public API documentation is employer-oriented: it requires an API key created by an employer and is designed to create, fund, manage and review that employer's tasks. It is not evidence of a public worker opportunity feed.

Profile fit:
- The existing country review had Armenia in the allowed-country list, but that does not establish acceptance of an Iranian passport or the user's actual KYC result.
- Keep the platform catalog-only and review-only until the user's signed-in account confirms current residence-country access, identity-document rules, and wallet withdrawal availability.
- Never attempt access from a prohibited country or use false location details.

Official references:
- https://microworker.app/about/
- https://microworker.app/eligibility/
- https://microworker.app/api-docs/
- https://microworker.app/developers/

## Loopuman

Official worker-facing information reviewed:
- Supports short tasks such as AI response evaluation/RLHF, data labeling, translation, writing, research, surveys, content moderation, local verification, and first-person video tasks.
- Workers receive 80% of the task budget after approval; the platform fee is 20%.
- The published minimum withdrawal is USD 1, with zero withdrawal fee.
- Worker payouts are described as USDm, USDT, or USDC on Celo; the worker experience references MiniPay/Valora and Telegram.
- Payout timing of about eight seconds is described as typical after approval, not guaranteed.
- The site advertises workers in 100+ countries, but individual tasks can be limited by location, skills, equipment, or verification.
- The public browse page includes example task cards; it does not establish a reliable anonymous live-task API. Do not label it a connected feed.
- Loopuman describes workers as verified humans, but the exact verification method and acceptance of an Iranian passport while residing in Armenia were not confirmed.

Profile fit:
- Keep catalog-only and review-only. Verify account registration, identity/KYC, Armenia availability, Iranian-passport acceptance, supported wallet route and actual task availability before spending time on a task.
- Do not buy platform credits or fund tasks; this project is a worker, not requester, workflow.

Official references:
- https://loopuman.com/microtasks
- https://loopuman.com/browse-tasks
- https://loopuman.com/platform/telegram
- https://loopuman.com/why-loopuman

## Integration decision

Neither platform is promoted to the live discovery feed in this review:
- Microworker's documented API is for employers and requires an employer API key; it is not a worker task feed.
- Loopuman's public browse page does not expose a verified anonymous worker-task feed, and the visible examples must not be mistaken for live jobs.

Both remain in the 25-platform catalogue with unresolved identity and profile eligibility checks. No paid API, account action, or automated task action was enabled.
