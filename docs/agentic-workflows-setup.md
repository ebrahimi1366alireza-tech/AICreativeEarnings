# راه‌اندازی GitHub Agentic Workflows (gh-aw)

این راهنما برای فعال‌سازی عامل هوش مصنوعی در فضای ابری GitHub Actions نوشته شده است. تا زمانی که مراحل زیر در Codespaces اجرا و موتور هوش مصنوعی احراز هویت نشود، هیچ عامل هوش مصنوعی فعالی در مخزن اجرا نخواهد شد.

## پیش‌نیازها

- دسترسی Write به این مخزن
- GitHub Actions فعال باشد: Settings → Actions → General
- GitHub CLI نصب و وارد حساب شده باشد: `gh auth status`
- یک موتور هوش مصنوعی پشتیبانی‌شده و اعتبار/حساب لازم آن

## نصب افزونه در Codespaces

از ریشه مخزن اجرا کنید:

```bash
gh extension install github/gh-aw
```

بررسی نصب:

```bash
gh aw version
```

اگر فرمان بالا نسخه را نشان نداد، خروجی خطا را بررسی کنید؛ نصب مجدد کورکورانه انجام ندهید.

## افزودن گردش‌کار گزارش روزانه (آزمایشی و فقط‌خواندنی)

```bash
gh aw add-wizard githubnext/agentics/daily-repo-status
```

در راهنمای تعاملی:
1. یک موتور هوش مصنوعی که واقعاً به آن دسترسی دارید انتخاب کنید.
2. نام Secret موردنیاز را طبق همان راهنما تنظیم کنید.
3. فایل workflow و فایل lock تولیدشده را بازبینی کنید.
4. اجرای اولیه را فقط پس از بررسی مجوزها و هزینه احتمالی تأیید کنید.

این نمونه برای تحلیل فعالیت مخزن و ساخت یک Issue گزارش است؛ مجوز نوشتن کد یا Merge خودکار به آن اضافه نکنید.

## نکات امنیتی و هزینه

- هیچ API Key یا توکنی را داخل کد، فایل workflow یا commit قرار ندهید؛ فقط از GitHub Actions Secrets استفاده کنید.
- مجوزها را حداقلی نگه دارید. برای مرحله اول، دسترسی خواندن محتوا، Issueها و Pull Requestها کافی است.
- خروجی عامل باید گزارش یا Issue باشد؛ تغییر کد، انتشار، حذف داده و Merge خودکار در مرحله آزمایشی ممنوع باشد.
- GitHub Actions سهمیه و محدودیت مصرف دارد. درخواست‌های مدل هوش مصنوعی نیز ممکن است هزینه جداگانه داشته باشند. پیش از فعال‌سازی، صورتحساب و سقف مصرف را بررسی کنید.
- عامل‌ها دائماً روشن نیستند؛ با زمان‌بندی یا رویداد GitHub اجرا می‌شوند و پس از پایان هر اجرا متوقف می‌شوند.

## پیگیری

- وضعیت اجرا: زبانه Actions مخزن
- وضعیت عامل‌ها: `gh aw status`
- اجرای دستی گردش‌کار: `gh aw run daily-repo-status`
